# Number-Quest-
A Python-based problem-solving game 
**Number Quest** is a beginner-friendly Python-based problem-solving game developed as a project for the **CSE1021 – Introduction to Problem Solving and Programming** course.

The project provides users with different number-based challenges such as **Number Guessing, Prime Challenge, and Fibonacci Challenge**. It also includes a scoring system and statistics section to make the application interactive.

The main purpose of the project is to apply basic Python programming concepts such as **variables, conditional statements, loops, functions, lists, modules, and problem-solving algorithms** in a practical application.

## Features

* 🎯 Number Guessing Challenge
* 🔢 Prime Number Challenge
* 🧮 Fibonacci Challenge
* 🏆 Score tracking
* 📊 Statistics display
* 📋 Interactive main menu
* ❌ Input validation and basic error handling

## How to Run

### 1. Install Python

Download and install **Python 3** on your computer.

### 2. Clone the Repository

```bash
git clone <your-github-repository-link>
```

### 3. Open the Project Folder

```bash
cd Number-Quest
```

### 4. Run the Program

```bash
python main.py
```

The game will start and display the main menu.

## How to Play

1. Enter your name when prompted.
2. Select an option from the main menu.
3. Choose a challenge:

   * Number Guessing
   * Prime Challenge
   * Fibonacci Challenge
4. Complete the challenge and earn points.
5. View your score and statistics.
6. Exit the program when finished.
