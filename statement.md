# Project Statement – Number Quest

## 1. Problem Statement

Beginners learning Python often understand individual programming concepts such as loops, conditional statements, and functions, but may find it difficult to combine these concepts to create a complete working application.

**Number Quest** addresses this problem by providing a simple interactive game where users can practice basic problem-solving and Python programming concepts through number-based challenges.

## 2. Scope of the Project

The project focuses on developing a console-based Python game that provides different number-related challenges.

The scope includes:

* Number Guessing Challenge
* Prime Number Challenge
* Fibonacci Challenge
* Score tracking
* Performance statistics
* User input and validation
* Interactive menu-based navigation

The project is designed as a beginner-level application and focuses on applying fundamental Python programming concepts.

## 3. Target Users

The primary target users are:

* Beginners learning Python programming
* Students studying basic problem-solving and programming
* Students who want to practice loops, conditions, functions, and numerical algorithms
* Users interested in simple educational programming games

## 4. High-Level Features

### Number Guessing

The user tries to guess a randomly generated number within a limited number of attempts.

### Prime Challenge

The user determines whether a given number is a prime number.

### Fibonacci Challenge

The user answers questions related to the Fibonacci sequence.

### Score System

The application tracks the user's score based on completed challenges.

### Statistics

The user can view basic performance information such as questions answered and score.

### Interactive Menu

A simple menu allows the user to select challenges, view results, or exit the application.
